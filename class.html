2 找到分卷文件（.001 / .part1.rar）

多种加密 / 多方法尝试：分件压缩合并 → 改后缀 → 使用 7-Zip 解压。
常见伪装：jpg / png / mp4 → 改后缀为 .7z .zip .rar 再解压。
1 安装 7-Zip 或 WinRAR
2 选中所有分卷（.rar / .r01 / .part1）
3 右键 → 7-Zip → 提取到当前位置
4 若报错 → 强制改后缀 + 换软件
